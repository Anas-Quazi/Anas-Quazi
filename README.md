## 🔬 Projects

### 🛢️ Petro-Analyst — India Fuel Price Prediction System
> Predicting LPG & fuel price impact of Middle East geopolitical conflicts on Indian households

- Collected 16 years of data (GPR index, Brent crude, USD/INR, LPG/fuel prices) from multiple sources
- Built 43 engineered features — lag, rolling averages, % changes, interaction terms
- Applied KNN similarity analysis to find historical parallels to current market conditions
- Deployed interactive dashboard with Flask — real-time risk classification & 3-month price forecast
- **Stack**: Python, Pandas, NumPy, Scikit-learn, Flask, Matplotlib, Seaborn

---

### 🏎️ F1 Business Analysis — Multi-Billion Dollar Business Intelligence
> Analyzing Formula 1 as a business ecosystem through SQL

- Designed a normalized schema with 14 tables and 1 view covering F1's entire financial structure
- Modelled sponsorships, engine contracts, driver salaries, factory expenses, revenue streams
- Wrote complex analytical queries — net profit/loss per team, partner networks, contract tracking
- **Stack**: PostgreSQL, SQL, Window Functions, CTEs

---

### 🔧 IoT Predictive Maintenance — Industrial Equipment Failure Prediction
> Predicting machine failures before they happen using sensor telemetry + external context

- Built a Contextual Data Fusion Framework combining IoT sensor data with weather and factory load
- Used LightGBM with SMOTE inside cross-validation folds for imbalanced classification
- Added SHAP explainability — identifying which sensor triggered each failure prediction
- Deployed as an interactive maintenance alert dashboard
- **Stack**: Python, LightGBM, SMOTE, SHAP, Scikit-learn, Pandas, Flask

---

### 🗺️ Geospatial Property Valuation — Real Estate Pricing via Graph Neural Networks
> Proving that a house's price is fundamentally spatial — not just tabular

- Identified core flaw in traditional AVMs — treating properties in isolation
- Built KNN graph where every house is a node, edges connect spatial neighbors
- Trained Graph Neural Network with attention mechanism — achieved ~7% MAPE vs ~12% XGBoost baseline
- **Stack**: Python, PyTorch, GeoPandas, XGBoost, Folium, Flask
